# Внешняя сверка свода правил книги (2026-10-19)

**Что проверяли.** Все `must`-правила и все детерминированные правила свода Суркова, всего 427 (кроме трёх, исправленных вручную по ревью §8.1). Пять агентов работали параллельно. Каждое правило получило:
- `authority` — на чём держится правило;
- `external_check` — расходится ли оно со стандартом;
- при конфликте или завышении — предложенную правку `severity` / `check.mode` / `modern_note`.

Текст правил (`statement`) не менялся. Правки применены скриптом, лог лежит в scratchpad сессии (`classify/merge-log.json`).

**Ограничение.** Часть агентов работала по своим знаниям стандартов, без веб-проверки. Номера разделов в ссылках (`standard_ref`) не все сверены с первоисточником. Перед тем как опираться на отдельную ссылку в споре, её нужно проверить.

## Как это используется
- В пакетах `rules_pack.py` правило с `must` и `authority` = `author-opinion` или `vendor-guideline` показывается как `should`. Такая находка не может быть P1 сама по себе.
- Остальные ~700 правил (`should`/`nice`, эвристики) пока `unclassified` и ведут себя как раньше. Их классификация — следующий шаг, по мере использования.
