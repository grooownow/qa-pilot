> Example for an invented project: a small online shop (catalog, cart, checkout, accounts).

## Stack
- TypeScript, pnpm, single package, Next.js 15 (App Router), React 19.
- Data: Postgres through Prisma; payments through a hosted payment provider (test mode in dev).
- Run locally: `pnpm dev` → `http://localhost:3000` (seed data: `pnpm db:seed`).

## Test landscape
- Playwright (e2e), Vitest (unit + component), MSW (network mocks for component tests).
- UI library `packages/ui`: Storybook 9 with the Vitest addon; 14 components, 5 stories with `play` tests.
- About 140 Vitest tests in `src/**/*.test.ts(x)`, 22 Playwright tests in `e2e/*.spec.ts`.
- Tags in e2e titles: `@smoke` (runs on every PR), `@full` (nightly).

## Error plumbing
- `src/lib/http/client.ts`: every failed request goes through `handleApiError`.
- Toasts: network failure, 5xx and 429 show a generic toast (`src/components/ui/toast.tsx`).
- Silent: 400 and 409 are not toasted; each form must render its own message.
- 401 redirects to `/login?next=<path>`.

## Commands
- All unit/component tests: `pnpm test:unit`. One file: `pnpm test:unit src/lib/cart.test.ts`.
- All e2e: `pnpm test:e2e`. One file: `pnpm test:e2e e2e/checkout.spec.ts`.
- Typecheck: `pnpm typecheck`. Lint: `pnpm lint`.
- Dev server: `pnpm dev` (port 3000).

## Conventions
- Locators: `data-testid` on every element a test touches, constants in `src/testIds.ts`; no CSS or XPath. See `docs/testing.md`. (`CONTRIBUTING.md` line 41 still says "use CSS selectors"; the code does not follow it.)
- Fixtures: `e2e/fixtures.ts` provides `loggedInPage` and `seededCart`; no page-object classes.
- Naming: `feature.spec.ts` for e2e, `<module>.test.ts` next to the source for unit.
- Network mocks: handlers in `src/mocks/handlers.ts`, one per endpoint.

## Critical flows
- Checkout and payment · `/cart` → `/checkout` · money is taken; a wrong total or a double charge is direct loss.
- Add to cart · `/products/[slug]` · every sale starts here.
- Login and password reset · `/login`, `/reset` · locked-out customers cannot buy.
- Order history · `/account/orders` · support load when it is wrong.
